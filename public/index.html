🐺 Les Loups de Brumeval

Loups-garous multijoueur · chat de proximité · nuits chronométrées

⚠️ Le micro ne fonctionne qu'en https (ou sur localhost). Utilisez l'adresse https affichée par le serveur.

Comment jouer
  • Z Q S D / W A S D / flèches : se déplacer
  • Entrée : écrire dans le chat — seuls les joueurs proches vous entendent
  • 🎙️ Activez le vocal : le volume dépend de la distance
  • La nuit, chaque rôle doit agir avant la fin du chrono, sinon son action est perdue
  • Les loups se retrouvent à la tanière et parlent entre eux ; les villageois dorment
🖱️ Glisser : tourner la caméra · Molette : zoom
